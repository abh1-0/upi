# UPI Studio - Product Context

## Purpose
UPI Studio is a developer and merchant tooling suite for generating unified NPCI-compliant Unified Payments Interface (UPI) payment artifacts:
1. Dynamic Vector/Canvas UPI QR Codes (Merchant Counter Standees)
2. App-to-App Mobile Deep Link Intent URLs (`upi://pay`, `gpay://`, `phonepe://`, `paytmmp://`)
3. Copy-paste "Pay with UPI" HTML/CSS buttons and universal fallback checkout scripts.

## Target Audience
- Indian digital commerce merchants, SMB retail store owners, freelancers, Shopify/WooCommerce store administrators.
- Frontend engineers needing zero-fee, direct peer-to-peer or peer-to-merchant UPI integration without 2-3% payment gateway commissions.

## Surface Mode
- **Operate Mode**: Developer-grade productivity workbench, high visual clarity, instant interactive reactive feedback, tactile micro-interactions, 8pt spatial grid rhythm, precision typography.
